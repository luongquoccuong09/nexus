# Interactive UI Mockups

These standalone HTML prototypes illustrate interaction flows and layout concepts. Open them directly in a browser.

- [`project-nexus-enduser-mockup.html`](project-nexus-enduser-mockup.html): End-user workspace prototype covering open DMs (`P0-D01`), password registration/sign-in (`P0-D03`/`P0-D13`), `Unverified` badge, simulated Google linking, and the Microsoft Teams-style **Community → optional sub-channels** layout (direct community feed + on-demand `+ Add channel`).
- [`project-nexus-m1-m2-mockup.html`](project-nexus-m1-m2-mockup.html): M1–M2 identity, directory, and core chat interaction prototype.

> **Important:** Mockups are **not** authorization or API specifications. Backend rules are defined in [`../SECURITY_AND_AUTHZ.md`](../SECURITY_AND_AUTHZ.md) and [`../API_CONTRACTS.md`](../API_CONTRACTS.md).
