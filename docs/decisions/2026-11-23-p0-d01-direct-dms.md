# Active users can open direct messages directly

Active accounts can initiate 1:1 direct messages without pre-approval, governed by account status, user blocking/reporting (`M2.11`), and daily new-DM limits for `Unverified` trial accounts (`M1.4b`).

**Why:** Internal communication requires low-friction peer messaging while still limiting abuse during open trial registration.

**How to apply:** Upsert 1:1 DMs by canonical `dm_key` so concurrent tabs open a single conversation (`M2.2`). Enforce `Active` status, block lists, and `Unverified` rate limits in `IAuthorizationService`.
