# Active members can open Organization direct messages directly

Active members of the same Organization can initiate an Organization direct message, governed by account status, user blocking/reporting (`M2.11`), and daily new-DM limits for `Unverified` members (`M1.4b`). Personal direct messages use the consent flow in [P0-D14](2026-11-23-p0-d14-personal-chat-and-organizations.md).

**Why:** Internal communication requires low-friction peer messaging while still limiting abuse during open trial registration.

**How to apply:** Upsert Organization DMs by canonical `dm_key` within that Organization so concurrent tabs open a single conversation (`M2.2`). Enforce `Active` account and membership status, block lists, and `Unverified` rate limits in `IAuthorizationService`.
