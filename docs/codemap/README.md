# Machine-Generated Code Map

Files in this directory (`SYMBOLS.md`, `CONTEXTS.md`, `EDGES.md`, and `symbols/*.md`) will be generated by `scripts/audit/Build-CodeMap.ps1` once feature modules grow in M0.2+.

- Do **not** hand-edit generated files.
- Use [`dynamic-edges.json`](dynamic-edges.json) to register non-obvious wiring that static grep cannot see (e.g., SignalR event names, outbox message types, dynamic route mappings).
- Always start navigation with [`../CODEMAP.md`](../CODEMAP.md).
